1. Find your phone's advertising ID. On Android: Settings -> Google -> Ads (or Settings -> Privacy -> Ads) shows it at the bottom. On iOS the ID isn't shown in Settings, so iPhone users can instead turn off "Allow Apps to Request to Track" under Settings -> Privacy & Security -> Tracking.
2. Go to https://www.t-mobile.com/advertising-solutions/opt-out, choose Android or iOS, paste the advertising ID and select "Opt out." Do this for each phone you use.
3. On each browser you use, open https://www.t-mobile.com/privacy-center/do-not-sell and switch the "Do Not Sell or Share" toggle off. Logged out, this is saved in a cookie, so it's lost if you clear cookies. Turning on Global Privacy Control in your browser has the same effect.
4. If you're a T-Mobile, Metro or Assurance Wireless customer, log in to each brand's account and set "Do Not Sell or Share" in the Privacy Dashboard (https://www.t-mobile.com/privacy-center/dashboard). If you opted in to Personalized Ads and Offers, turn that off too.
5. To have your data deleted, start a personal data request from https://www.t-mobile.com/privacy-center/education/about-personal-data-requests and pick the category that fits you. T-Mobile verifies your identity, which can include a government ID, and answers within 45 days.
6. If you reset your advertising ID later, the new ID isn't opted out, so repeat step 2.
