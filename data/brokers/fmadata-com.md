1. Go to https://www.fmadata.com/opt-out-requests/new.
2. Select the request type: opt out of sale/sharing, request disclosure of data held, or request deletion.
3. Enter your full name and address so FMAdata can match your record in its homeowner/property database.
4. If submitting on someone else's behalf, indicate "authorized agent" and provide the agent's name.
5. Submit the form; alternatively, FMAdata offers a printable PDF version of this same request that can be mailed to their Privacy Desk if you prefer not to submit personal information online.
6. No opt-out-specific email address was found on the live site -- use the web form or mail option above rather than emailing FMAdata directly.
