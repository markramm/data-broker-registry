1. Go to the [Blackbaud Data Subject Rights Request page](https://www.blackbaud.com/company/data-subject-rights-request).
2. Choose the request type: deletion, correction, access, or opt-out of sale/sharing.
3. Fill in the web form with your name and email address (if you are an authorized agent instead of the individual, use the separate agent request form and be ready to show consent).
4. Submit the request. Blackbaud may follow up to verify your identity, which can include a request for government ID.
5. If you'd rather not use the web form, call 1-844-532-0022 to submit the request by phone instead.
