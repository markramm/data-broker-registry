# Design notes — Make Yourself Expensive

## Thesis
The page is a **surveillance dossier you are clearing**. Signature = the **strikethrough**:
opting out of a broker visibly strikes its row from the ledger (a name crossed off a list —
the Hortman notebook image inverted into agency). Progress = the visible accumulation of
struck rows, not a progress bar.

## Tokens
- Palette "redacted document": paper #EDE9E0 (manila/dossier), ink #16130E, redact #1A1814,
  seal #8A1C1C (classified-stamp oxblood — the ONLY accent, used sparingly), graphite #6B6459,
  rule #C9C1B2.
- Type: DISPLAY = monospace/typewriter (a list of names IS typed — dossier/FOIA/notebook).
  BODY = quiet humanist serif (newsroom prose). Mono doubles for counters/pills (data wants mono).
- Layout: a working document, not a landing page. Typed header + live tally; the broker register
  IS the page; struck rows get a redaction bar + strikethrough and sink.

## Rejected (generic-default cluster — do NOT drift back)
- cream+serif+terracotta / black+acid-green / broadsheet-hairlines. Paper is manila-dossier not
  cream; accent is classified-oxblood not terracotta/neon; display is typewriter-mono not contrast-serif.
- Numbered rows are OK here ONLY because a ledger has real priority sequence (crucial first).

## Risk taken
Strikethrough-as-progress + full-UI typewriter display face. Justified by: ONE clean strike
animation (reduced-motion respected), everything else dead quiet. Spend boldness only here.

## Quality floor
Responsive to mobile, visible keyboard focus, prefers-reduced-motion respected, no layout shift
on strike. Keep the strike from feeling AI-gimmicky: subtle, fast, once per row.
